import { colorTokens, contrastPairs, typeScale } from "@/config/tokens/accessibility"

const describeRating = (measurement) => {
  if (measurement.ratings.aaa) {
    return "AAA"
  }

  if (measurement.ratings.aaNormalText) {
    return "AA"
  }

  if (measurement.ratings.aaLargeText) {
    return "AA (Large Text)"
  }

  return "Below AA"
}

# Color & Typography Accessibility Tokens

These tokens document the core color palette and typography scale for the Share House Portal. Each color pair is measured for contrast in both light and dark modes to guarantee WCAG AA compliance. The automated Vitest check in `tests/accessibility/contrast.spec.ts` will fail the build if any required pair drops below a 4.5:1 ratio.

## Type Scale

The typography scale mirrors the Tailwind CSS defaults resolved from `tailwind.config.ts`. Large text (≥ 24px) qualifies for the relaxed 3:1 ratio, while body sizes require the standard 4.5:1 contrast.
